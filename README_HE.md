# Maple Flip Hunter — מדריך בעברית

תוכנה לווינדוס שמנטרת אוטומטית את כל השוק החופשי (Free Market) של MapleStory Classic World כפי שהוא נראה
במקורות נתונים ציבוריים, מזהה פריטים שמוצעים במחיר נמוך משמעותית מערכם, ומשמיעה אזעקה.
**אין צורך לבחור פריטים ידנית** — המערכת סורקת את כל הפריטים שמגיעים מהמקורות.

התוכנה **לא** קונה, **לא** זזה במשחק, **לא** נוגעת בלקוח המשחק ולא מבקשת סיסמאות. היא רק מתריעה ומראה איפה החנות.

---

## 1. התקנה

### אפשרות א — קובץ מוכן (EXE)
1. הורד את `MapleFlipHunter-win64.zip` (מתיקיית ה-Artifacts של ה-GitHub Actions או מהמסירה).
2. חלץ את התיקייה לכל מקום (למשל `C:\Games\MapleFlipHunter`).
3. לחץ פעמיים על `MapleFlipHunter.exe`.
4. אם Windows SmartScreen מציג אזהרה (הקובץ לא חתום דיגיטלית): "מידע נוסף" → "הפעל בכל זאת".

### אפשרות ב — הרצה מהקוד
1. התקן Python 3.11 ומעלה מ-python.org (סמן "Add python.exe to PATH").
2. לחץ פעמיים על `run_dev.bat` — הוא יוצר סביבה וירטואלית, מתקין תלויות ומפעיל את התוכנה.

### בניית EXE בעצמך
`build\windows\build_exe.bat` → התוצאה ב-`dist\MapleFlipHunter\MapleFlipHunter.exe`.

## 2. הפעלה
* התוכנה מתחילה לסרוק מיד עם הפתיחה (אפשר לעצור/להפעיל בכפתור **Start/Stop scanner**).
* בראש המסך: מצב הסורק — **LIVE** (נתונים טריים מתקבלים), **DEGRADED** (מקור איטי/מוגבל), **OFFLINE**.
* **Test alarm** — משמיע את צליל הטווח הגבוה ביותר כדי לכוון עוצמה.
* סגירת החלון (X) **לא** סוגרת את התוכנה — היא ממשיכה לרוץ במגש המערכת (ליד השעון). לחיצה כפולה על האייקון פותחת
  מחדש; קליק ימני → Quit כדי לצאת.

## 3. מה רואים
* **טבלת ההזדמנויות** — 6 עמודות: פריט · מחיר קנייה · מכירה מהירה · רווח נטו · גיל המודעה · מיקום (CH · FM).
  רווח חיובי ירוק / הפסד אדום; מודעה טרייה ומאומתת ירוקה, לא ודאית כתומה, ישנה אפורה. הגיל מתעדכן כל שנייה.
  לחיצה על כותרת ממיינת (למשל רווח מהגבוה לנמוך); ברירת מחדל — החדש ביותר למעלה.
  כל שאר המידע (רווח נטו, תשואה, ביטחון, נזילות, טריות, ערוץ/חדר/חנות, מקור, סטטים) בפאנל הפרטים מימין.
* **פאנל פרטים** (בלחיצה על שורה): תמונת הפריט, סטטים, מחירים, מתחרים חיים, מכירות שהושלמו, הסבר התמחור, סיכונים,
  מיקום מדויק וקישור למקור. כפתורי **Copy shop name / Copy FM location** מעתיקים ללוח.
* **פס מצב**: מקורות מחוברים, גיל הנתונים החדשים ביותר, מספר רשומות חדשות, זמן ממוצע ממקור→התראה ומקליטה→צליל (נמדד לכל התראה), כיסוי השוק.

## 4. התראות
* **הצליל נקבע לפי הרווח נטו שחושב בפועל** (המספר בעמודת Net profit), לא לפי הכותרת. ברירות מחדל:
  10,000–19,999 פעמון קצר ועדין · 20,000–49,999 מנגינה קצרה ושמחה · 50,000 ומעלה מנגינת JACKPOT חגיגית.
  כל הצלילים מלודיים ורכים (בלי סירנות). ב-Settings → "Sound alerts by NET PROFIT": עריכת גבולות, הפעלה/כיבוי,
  בחירת צליל, ▶ Preview, עוצמה, "+ Add band" לטווחים נוספים. טווחים חופפים לא יישמרו (מוצגת הודעה).
  טווח כבוי או רווח מחוץ לכל טווח = שורה והודעת Windows בלי צליל.
* **זמינות**: ההתראה יוצאת מיד; אחריה בדיקה ברקע אם המודעה עדיין קיימת (לפי מה שהמקור יודע). בפאנל הפרטים:
  ACTIVE = נצפתה לאחרונה (לא הבטחה) · UNVERIFIED = אין אימות עדכני (עם הסיבה) · REMOVED = הוסרה/שונה מחיר · SOLD = רק עם
  ראיה מפורשת למכירה, ו-Last verified. מודעות שאומתו כמוסרות/נמכרו יוצאות מהטבלה (נשמרות במסד); הכרטיס הצף מתעדכן בלי צליל נוסף.
  Cozy לא מאפשר אימות; maplestory.watch מאשר באיחור של עד 5 דק' (מטמון האתר).
* **כרטיס התראה מעל כל החלונות** לכל JACKPOT / GOOD FLIP שעבר את כל הסינונים: פריט, מחיר קנייה, רווח נטו **משוער**
  (מסומן "not guaranteed"), מיקום מדויק, ביטחון וזמן ההתראה. כפתורים: **Copy location** (לחיצה אחת ללוח), **Mute**
  (עוצר את הצליל ומשתיק 60 שניות), **OK** — הכרטיס נשאר עד שלוחצים. הכרטיס לא גונב פוקוס מהמשחק.
  מגבלת Windows: משחק במסך מלא *בלעדי* (exclusive fullscreen) מסתיר כל חלון אחר — הצליל וההודעה עדיין פועלים, והכרטיס
  ממתין ב-Alt+Tab. במצב חלון / borderless הכרטיס מופיע מעל המשחק. מומלץ להגדיר את המשחק ל-borderless windowed.
* **JACKPOT** — בנוסף: באנר אדום בראש המסך ל-45 שניות, הודעת Windows, החלון קופץ.
* **GOOD FLIP** — הודעת Windows + שורה בטבלה.
* **UNCERTAIN** — רק בטבלה, בלי צליל (המידע לא מספיק לוודא ערך/ביקוש).
* אותה רשומה לא מתריעה פעמיים. אם המוכר הוריד מחיר — זו הזדמנות חדשה ותתקבל התראה חדשה.
* **Freshness** — רשומות שהמקור ראה לפני יותר מ-15 דקות מסומנות stale ולא מתריעות.

## 5. הגדרות (כפתור Settings)
החלון נגלל, כפתורי Save/Cancel תמיד למטה, ניתן לגרירה ושינוי גודל, וזוכר את מקומו וגודלו.
| הגדרה | ברירת מחדל | הסבר |
|---|---|---|
| Minimum purchase price | 2,500 | לא מתריעים ולא מציגים בטבלה פריטים זולים מזה |
| Maximum purchase price | 10,000 | לא מתריעים ולא מציגים בטבלה פריטים יקרים מזה |
| QUICK FLIPS ONLY | כבוי | התראה רק כשהרווח לפי מכירה שמרנית (אחרי עמלה) ≥ 10,000, ביטחון ≥ 80%, נתונים בני עד 5 דקות ונזילות גבוהה; חסר מידע = אין התראה |
| Minimum net profit | 15,000 | רווח נטו מינימלי אחרי עמלה — מסנן גם את הטבלה, מיד עם השמירה (הנתונים נשמרים במסד) |
| Selling fee | 3% | עמלת מכירה; ניתנת לשינוי |
| JACKPOT thresholds | רווח ≥ 50,000 או (תשואה ≥ 100% ורווח ≥ 25,000) | |
| Minimum confidence | JACKPOT 60%, GOOD 45% | ציון ביטחון מוסבר בפאנל |
| Treat listings older than | 900 שניות | מעבר לזה — stale |
| Sources | cozy.markets כל 10 ש', maplestory.watch כל 3 דק', Club FM כל 60 ש' | שינוי מקורות מפעיל מחדש את הסורק |
| FM Watcher folder | ריק | **מקור LIVE שני מהסריקות שלך**: הרץ את FM Watcher של Club FM (חינמי, קורא רק את המסך) ובחר כאן את התיקייה שלו; כל חנות שאתה פותח ב-FM נכנסת תוך שניות לזיהוי ולהתראות. לא נשלח כלום לשום מקום. |
| Club FM (maplefm.gg) | כבוי | לסמן **רק** אחרי אישור בכתב מצוות Club FM; טוקן (אם ניתן) מפעיל את `/data/live`, אחרת snapshot |
| Run when Windows starts | כבוי | רישום למשתמש הנוכחי בלבד |

הקבצים נשמרים ב-`%APPDATA%\MapleFlipHunter` (הגדרות, מסד נתונים, לוגים, צלילים).

## 6. פתרון בעיות
| תופעה | מה לעשות |
|---|---|
| המצב נשאר OFFLINE | בדוק חיבור לאינטרנט; פתח בדפדפן את https://cozy.markets/market — אם האתר לא עולה, גם התוכנה לא תקבל נתונים. ראה `%APPDATA%\MapleFlipHunter\logs\maple_flip_hunter.log`. |
| DEGRADED / RATE LIMITED | המקור ביקש להאט; התוכנה ממתינה אוטומטית. אפשר להגדיל את מרווח הסריקה בהגדרות. |
| אין צליל בהתראה אוטומטית | Settings → **🧪 Test Automatic Alert** — מריץ את המסלול האמיתי (thread רקע → צליל → כרטיס צף). אם נשמע — המערכת תקינה. אם לא: פתח `%APPDATA%\MapleFlipHunter\logs\maple_flip_hunter.log` וחפש `AUDIO_`: `AUDIO_STARTED thread=gui` = הצליל נשלח לכרטיס הקול; `AUDIO_SUPPRESSED reason=…` מסביר למה הושתק (Mute, Alerts כבוי, טווח רווח כבוי); `AUDIO_ERROR` = תקלת מערכת שמע. |
| אין צליל | לחץ Test alarm; בדוק שמכשיר הפלט של Windows תקין; הסליידר Vol לא ב-0. |
| אין הודעות Windows | כבה "Focus Assist / נא לא להפריע". הצליל מושמע גם כשההודעות מושתקות. |
| אנטי-וירוס חוסם את ה-EXE | קבצי PyInstaller לא חתומים לעיתים מסומנים; הרץ מהקוד עם `run_dev.bat`. |
| הרבה UNCERTAIN ומעט התראות | זה מכוון: ציוד בלי סטטים ידועים ופריטים בלי היסטוריית מכירות לא מקבלים אזעקה. אפשר להוריד את סף הביטחון בהגדרות (על אחריותך). |
| פריט שראית במשחק לא מופיע | אף סורק קהילתי לא ראה את החנות הזו. הכיסוי תלוי בשחקנים שמריצים סורקים (ראה docs/LIMITATIONS.md). |
